# CSS-INTERNAL

Internal assets for Creative Sold Separately, kept apart from the website and the 3D asset catalogue.

The repo is public so email apps can load the images. Nothing private goes here.

## email-signature

Spencer Fahlman's email signature, the Overprint concept in nine versions. Every hero GIF is 920 × 200, a 15 s loop, shown at 460 × 100.

| Version | Hero GIF | Paste-ready signature |
|---|---|---|
| 01 Riso | `overprint-riso.gif` | `signature-01-riso.html` |
| 01B Riso · Made together | `overprint-riso-made-together.gif` | `signature-01B-riso-made-together.html` |
| 02 Ink | `overprint-ink.gif` | `signature-02-ink.html` |
| 03 Kafka | `overprint-kafka.gif` | `signature-03-kafka.html` |
| 04 Orange | `overprint-orange.gif` | `signature-04-orange.html` |
| 05 Ink · Stacked | `overprint-ink-stacked.gif` | `signature-05-ink-stacked.html` |
| 06 Ink · Rhythm | `overprint-ink-rhythm.gif` | `signature-06-ink-rhythm.html` |
| 07 Ink · Tracked | `overprint-ink-tracked.gif` | `signature-07-ink-tracked.html` |
| 08 Riso · Stacked | `overprint-riso-stacked.gif` | `signature-08-riso-stacked.html` |

`signature-plain.txt` is the plain-text fallback.

To install: open a signature's HTML file in a browser, select everything, copy, and paste into your mail app's signature settings.

Images load from jsDelivr: `https://cdn.jsdelivr.net/gh/CreativeSoldSeparately/CSS-INTERNAL@main/email-signature/<file>`

Renaming or moving a file breaks every signature that points at it.
